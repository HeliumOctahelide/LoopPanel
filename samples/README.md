# Sample Backgrounds

**English** | [简体中文](README.zh-CN.md)

This directory contains three original 16:9 abstract backgrounds made for LoopPanel:

- `aurora-circuit.jpg`: cool light trails and circuit textures; the bundled default.
- `liquid-alloy.jpg`: black/silver liquid metal with blue and orange reflections.
- `orbital-glass.jpg`: blue glass orbits with coral highlights.

These images were generated for this project with OpenAI's image-generation tool on 2026-08-14. They contain no JONSBO product photographs, trademarks, or official assets and are distributed under the project license.
